Migrate my Python FastAPI in-memory task CRUD API to SQLite.

Requirements:
- Use Python 3.10+ with FastAPI and the built-in sqlite3 module.
- Store data in a file named tasks.db next to the app.
- Create a tasks table if it does not exist with columns: id (integer primary key), title (text), done (integer 0/1).
- On startup, count rows first and seed exactly three example tasks only when the table is empty. Never duplicate seed data on restart.
- Wrap the seed inserts in a transaction so all three rows succeed or fail together.
- Keep these endpoints with the same behaviour as before:
  - GET /tasks
  - GET /tasks/{id}
  - POST /tasks
  - PUT /tasks/{id}
  - DELETE /tasks/{id}
- POST returns 201, DELETE returns 204, invalid body returns 400, unknown id returns 404.
- Use parameterized SQL queries with ? placeholders for every user-supplied value. Never build SQL with f-strings.
- Return JSON errors in the exact shape {"error": "Task not found"} for missing ids and {"error": "Title cannot be empty"} for validation failures.
